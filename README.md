# KlackType

물리 키보드로 타이핑할 때마다 골라둔 소리가 나는 Windows 앱입니다.
메모장이든 엑셀이든 게임 채팅이든, 어떤 프로그램에서 타이핑하든 소리가 따라옵니다.

이 저장소는 **설치 파일 배포용**입니다. 소스 코드는 포함되어 있지 않습니다.

## 다운로드

[**KlackType Setup 1.0.0.exe 받기 (77MB) →**](https://github.com/nexa101/Key-tone-change-0725/releases/download/v1.0.0/KlackType-Setup-1.0.0.exe)

Windows 10 / 11 (64비트)

## 받는 도중에 경고가 두 번 뜹니다 — 정상입니다

이 파일에 아직 코드 서명 인증서가 붙어 있지 않아서, 브라우저와 윈도우가 처음 보는 프로그램으로 취급합니다. 파일이 손상되었거나 악성이라는 판정이 아닙니다.

1. **받기** — 브라우저가 "일반적으로 다운로드되지 않습니다"라고 하면 파일 옆 `⋯` → `계속` (엣지는 `보관`)
2. **실행** — "Windows의 PC 보호" 창이 뜨면 `추가 정보` → `실행`
3. **설치** — 다음 → 완료. 작업표시줄 알림영역에 아이콘이 생기면 끝입니다.

인증서를 붙이면 두 경고 모두 사라집니다. 준비되는 대로 적용할 예정입니다.

백신이 차단하는 경우도 있습니다. 키 입력을 감지하는 기술 자체가 키로거와 같아서 행위 기반으로 오탐하는 경우가 있습니다 — 아래 항목을 읽어보시고, 그래도 차단되면 백신 예외 목록에 설치 폴더를 추가해 주세요.

## 키 입력을 기록하지 않습니다

키 입력을 감지하는 프로그램이라 의심스러운 게 당연합니다. 어디까지 다루고 어디부터 안 다루는지 밝힙니다.

- **다루는 것** — 키가 눌렸다는 신호와, 그 키가 스페이스인지 엔터인지 정도의 구분. 소리를 고르는 데만 씁니다.
- **버리는 것** — 어떤 글자였는지는 소리를 낸 직후 사라집니다. 파일에도 남기지 않습니다.
- **보내지 않는 것** — 타이핑과 관련해 어떤 서버와도 통신하지 않습니다. 인터넷이 끊겨도 그대로 동작합니다.
- **확인하는 방법** — 방화벽에서 이 앱의 네트워크를 차단해 보세요. 소리는 평소와 똑같이 납니다.

## 기능

- 시스템 전역에서 키 입력 감지 — 창을 옮겨도 끊기지 않습니다
- 소리 프리셋 여러 종 (기계식·타자기·빗소리·피아노·명상음·실제 녹음 등)
- 대부분의 소리는 파일 재생이 아니라 그 자리에서 만들어 냅니다. 매번 미세하게 달라져서 기계적으로 반복되지 않습니다
- 작업표시줄 알림영역 상주, 윈도우 시작 시 자동 실행
- `Ctrl+Alt+K`로 즉시 음소거

## 설치 프로그램을 쓸 수 없는 경우

회사 PC 등 설치가 제한된 환경에서는 압축본을 쓰실 수 있습니다.

[KlackType-1.0.0-win.zip (104MB)](https://github.com/nexa101/Key-tone-change-0725/releases/download/v1.0.0/KlackType-1.0.0-win.zip)

**반드시 폴더를 하나 만들고 그 안에 압축을 완전히 푼 뒤**, 그 폴더의 `KlackType.exe`를 실행하세요.
압축 파일 창 안에서 바로 더블클릭하면 `ffmpeg.dll이 없어 코드 실행을 진행할 수 없습니다` 오류가 납니다. 필요한 파일 130개가 같이 안 나와서 생기는 문제입니다.

## 사용된 음원

실제 녹음 기반 소리는 [Freesound](https://freesound.org)의 CC0(퍼블릭 도메인) 음원을 사용했습니다.
나머지 소리는 오디오 파일 없이 실시간으로 합성됩니다.
